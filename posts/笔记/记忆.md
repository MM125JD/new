# 什么是向量搜索

# 向量相似度（Vector Similarity）
**向量相似度（Vector Similarity）**，简单来说，就是**让计算机像人类一样，根据“含义”而不是“字面文字”来判断两段话是否相似的一种数学方法。**

传统的搜索（比如按 `Ctrl + F`）是严格的“关键词匹配”——你搜“开心”，文章里如果写的是“高兴”或“愉悦”，传统搜索就找不到。

而**向量相似度**解决的就是这个问题：**即使字完全不一样，只要意思是同一个事，它就能找出来。**

### 💡 它的底层逻辑是怎么运作的？（三步走）

#### 1. 现实世界 ➔ 维度坐标（Embedding 嵌入）

当你在 OpenClaw 中配置了嵌入提供商（比如 OpenAI 或 Ollama 的 Embedding 模型）后，模型会把你的每一句笔记或文本，转换成一组包含成百上千个数字的**高维向量（可以想象成在多维空间里的一个点/坐标）**。

模型在把文字变成坐标时，会把**语义相近的词，摆在空间里距离很近的位置**：

- 坐标轴 1（情感）：偏向正面 ➔ `[开心, 高兴, 愉悦]` 在一起
    
- 坐标轴 2（领域）：偏向计算机 ➔ `[代码, 编程, 算法]` 在一起
    

#### 2. 计算空间距离（相似度算法）

当你在 OpenClaw 中发起搜索，比如询问：_“我之前对项目架构有什么想法？”_

系统会把这句话也变成一个空间坐标，然后用数学公式（最常用的是**余弦相似度 Cosine Similarity**）去计算你的提问坐标与数据库中所有记忆坐标之间的**夹角**：

- **夹角越小（得分越接近 1）** ➔ 代表两段话在语义上越接近。
    
- **夹角越大（得分越接近 0 或负数）** ➔ 代表毫无关联。
    

#### 3. 提取结果

系统把得分最高（比如相关度最高的前 3 条）记忆片段翻出来，交给 AI 供其参考回答。

### 🔍 为什么 OpenClaw 要采用“混合搜索（Hybrid Search）”？

你提到的这句话点出了核心逻辑：**单一的“向量相似度”其实也有短板。**

|**搜索方式**|**擅长找什么**|**软肋是什么**|**典型例子**|
|---|---|---|---|
|**向量相似度 (语义搜索)**|**概念、感受、意图、大意**|对精准的专属名词、代码变量名不敏感。|你搜“_感到沮丧_”，它能帮你找到“_今天和弟弟吵架心情不好_”。|
|**关键词匹配 (精确搜索)**|**代码符号、变量名、ID、特定日期**|搜不到同义词，对错别字或换个说法完全没辙。|你搜 `MEMORY.md` 或 `user_id_9527`，它能精准定位到那个文件名或编号。|

#### 💡 结合后的混合搜索（Hybrid Search）：

当你配置了嵌入提供商后，OpenClaw 会**把两种算法打分融合在一起**：

- 既能理解你模糊、抽象的“意思”（靠向量相似度），
    
- 又不会漏掉固定的“代码符号、ID、技术术语”（靠关键词匹配）。
    

这种结合，能让 `memory_search` 在检索过去日记和知识库时达到最高的准确率。
