You have already learned about basic types but functions themselves also have a type. Kotlin's type inference can infer a function's type from the parameter type. But there may be times when you need to explicitly specify the function type. The compiler needs the function type so that it knows what is and isn't allowed for that function.如何理解

这段话的核心意思是：在 Kotlin 中，**函数是一等公民（First-class citizen）**，可以像 `Int` 或 `String` 一样被赋给变量、作为参数传递或作为返回值。因此，函数本身也有自己的“类型”（Function Type）。显式声明函数类型，本质上是在为编译器制定一份“契约”。

  

### 1. 如何理解“函数也有类型”？

普通变量的类型决定了它能存什么数据，而函数的类型决定了它**接收什么参数**以及**返回什么结果**。

  

函数的类型表示法为：`(参数类型列表) -> 返回值类型`

  

| **函数定义示例**                        | **函数类型**            | **解释**                       |
| --------------------------------- | ------------------- | ---------------------------- |
| `fun add(a: Int, b: Int): Int`    | `(Int, Int) -> Int` | 接收两个 `Int`，返回一个 `Int`        |
| `fun printMsg(msg: String): Unit` | `(String) -> Unit`  | 接收一个 `String`，不返回有效值（`Unit`） |
| `fun getRandom(): Double`         | `() -> Double`      | 无参数，返回一个 `Double`            |

### 2. 类型推导 vs 显式指定

**自动推导（Implicit Inference）：**

Kotlin 的编译器足够聪明，如果你在 Lambda 表达式里写明了参数类型，它会自动推导出函数的类型：

  

Kotlin

```
// 编译器自动推导出 multiply 的类型是 (Int, Int) -> Int
val multiply = { a: Int, b: Int -> a * b }
```

**显式指定（Explicit Specification）：**

有些场景下，编译器无法推导，或者显式声明能带来更好的代码可读性：

  

1. **简化 Lambda 内部语法**：如果在左侧声明了函数类型，右侧 Lambda 就不必重复写参数类型。
    
      
    
    Kotlin
    
    ```
    // 显式指定函数类型为 (Int, Int) -> Int
    val multiply: (Int, Int) -> Int = { a, b -> a * b }
    ```
    
2. **定义高阶函数（Higher-order Functions）**：将函数作为参数传递时，必须显式指定函数类型，否则编译器不知道该传什么。
    
      
    
    Kotlin
    
    ```
    fun performOperation(a: Int, b: Int, operation: (Int, Int) -> Int): Int {
        return operation(a, b)
    }
    ```
    
3. **处理可空类型（Nullable Function Types）**：声明一个可能为 `null` 的函数变量。
    
      
    
    Kotlin
    
    ```
    // 加上问号表示这个函数变量可以为 null
    var onClickListener: ((View) -> Unit)? = null
    ```
    

### 3. 为什么编译器需要知道函数的类型？

编译器需要知道函数类型来执行**编译期安全检查**（Type Checking），限制哪些行为是被允许的：

  

- **数量与类型限制**：声明了 `(Int) -> String`，就**不允许**传入 2 个参数，也不允许传入 `Boolean` 类型的参数。
    
      
    
- **返回值限制**：声明了返回 `Boolean`，如果 Lambda 表达式最后一行输出了 `String`，编译器会直接报错。
    
      
    
- **调用限制**：编译器知道这是一个函数变量，才允许你使用 `()` 或 `.invoke()` 来执行它，而不能对其进行加减乘除。
    
      
    

### 总结

- **函数类型**是函数的“身份标志”（参数 -> 返回值）。
    
      
    
- **自动推导**让你少写代码，**显式指定**让你在定义高阶函数、处理可空函数或精简 Lambda 时有明确的标准。
    
      
    
- **编译器依赖类型**来拦截非法调用，确保代码在运行前就是绝对安全的。
